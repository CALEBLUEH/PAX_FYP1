18 October 2026, trip rotation 7, isolated `CodexWorkspace` from `99717c5`. One player-entry milestone for the existing finite Quiet Shoal Resource Expedition and Lowtide Chart. Both are available; there is no unlock/profile/progression framework or new episode.

## Player flow

The new review build opens `PaxExpeditionSelection`. The authored cards explain each premise, resource/repair objective, mission action and fresh-world/save policy. Choose **1 Quiet Shoal**, **2 Lowtide**, a card button, or UI navigation with Tab/arrows and Enter. Window focus and release of held controls are required before a launch. Duplicate launch attempts are rejected while the single scene transition owns loading.

Every launch opens a fresh authored world with its original starting stocks (zero) and empty session discovery/activation journal. It does **not** load a snapshot automatically. Inside that expedition, **F9** explicitly loads its existing combined tiles + stocks snapshot; **F5** saves both and **F8** loads the previous valid snapshot. Per-scene slots, world signatures, conservation validation and session-only journal behavior are retained. **F6** restarts only the journal, keeping world/stocks and saved files.

From an expedition, Escape opens the existing pause/help overlay. **Return to expedition selection…** opens a separate discard confirmation. It explicitly states that the live world/resource state and entire session journal are discarded, with saved files retained and no implicit save/load. **Cancel** is the default focused button. Cancel or a fresh Escape returns to the same paused expedition; it does not resume, move the player, change velocity, modify construction/stocks/discoveries or touch files. A separate **Discard unsaved state & return** button is required to leave. The opening click, held keys and focus regain cannot confirm a discard. Focus loss keeps the expedition paused.
