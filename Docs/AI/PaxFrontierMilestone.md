## Implementation boundary

`PaxFrontierDefinition` composes an existing island definition with two bounded repair knobs. `PaxFrontierLayout` is a pure deterministic overlay using the existing generated tile/structure types. `PaxGeneratedFrontier` stores provenance and explicit scene references only. `PaxFrontierAuthoring` validates independent expected root against actual `Application.dataPath` before mutations, validates definition/output path before opening a scene, clones the wired finite rig into the new path, then replaces only that new scene's generated content. Existing runtime resource, save, world, mission, pause and input components are reused unchanged. The existing opt-in smoke dispatcher gains one guarded frontier probe branch.

The dedicated Windows review build opens the new scene directly: `Builds/PAX-Frontier-Windows/PAX.exe`. The build method is `Pax.Editor.PaxFrontierAuthoring.BuildWindows`; it passes an explicit one-scene list. New generated scenes are appended to isolated Editor Build Settings for practical PlayMode/direct authoring; previous entries/config objects remain intact.
