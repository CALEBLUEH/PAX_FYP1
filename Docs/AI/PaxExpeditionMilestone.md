# PAX survey beacon expedition

16 October 2026 trip rotation 2. One observable milestone, isolated `CodexWorkspace` from `54bcfa5`: give exploration and construction a small original purpose while retaining the sandbox.

## Playable loop

Open `Assets/PAX/Scenes/PaxExpedition.unity`. Survey the amber floor marks inside the house, cave and ruin in any order. A grounded player must stay within the mark's editable radius and height tolerance for 0.4 seconds; moving the camera or standing on a roof does not count. Each shelter has a short original field note. The authored right-hand HUD shows unread/surveyed shelters, distances and grid coordinates, current instructions, platform count and persistence rules.

Rebuild the six cyan platform cells near spawn with existing RMB placement. Aim at the ground in the outlines; build the far row first from spawn or walk around to keep line of sight clear. LMB removes mistakes. The outlines ignore targeting/collision and disappear only when their exact cells contain enabled, active, non-trigger registered tile colliders. Unrelated placements do not count. Early construction is allowed, but surveying is still required.

Jump onto the one-tile-high platform and press **F** beside the amber beacon to send the signal. Surveys, all six actual solid cells, grounded proximity and explicit activation are required. Completion turns the beacon green and leaves all sandbox controls available. Removing a required tile interrupts the signal; repairing it requires another activation. Repeated activation has no additional world effects or rewards.

**F6 restarts the session journal**, keeping construction and save files. This gives a replay route without discarding player edits. F5/F9/F8 still save/load/load previous **tile edits only**. Survey visits and activation are deliberately session-only and reset on scene reload. Repair progress is inferred from the current world, so loading complete/incomplete construction updates the objective and never restores visits or remotely activates the beacon. No save schema change or automatic save/load is added.

## Editable authoring and protection

- The expedition is a new saved scene cloned from the generated island. `PaxPrototype.unity` and `PaxGeneratedIsland.unity` remain available and unchanged. The original generator manifest remains provenance for the underlying terrain; the expedition's targeted bay/platform/support changes are separately authored.
- `Editable survey expedition` contains three survey discs, six repair blueprint objects, the beacon visual, activation marker and objective/input components. Inspect `PaxSurveySite` for title/note/radius/height/dwell/colors, `PaxRepairMarker` for explicit world/renderer references (its Transform defines the grid cell), `PaxExpedition` for references, stage/feedback text, activation tolerances and beacon colors, and `PaxExpeditionInput` for F/F6 keys.
- UI is authored in `Assets/PAX/UI/Expedition.uxml`; `PaxExpeditionHud` presents state beside the existing HUD without adding runtime UI objects. All references are saved; no additional Inspector assignments or packages are required. If changing input keys, update the editable UXML/objective hint text as well.
- `PAX > Create survey expedition if missing` / `PaxExpeditionAuthoring.CreateExpedition` refuses to modify an existing expedition. It never rewrites saves. Batch authoring/build uses the same independent `-paxAuthoringProject <expected absolute root>` vs actual `Application.dataPath` guard as the generator. The guard was exposed for reuse rather than duplicated.
- The scene has its own `pax-expedition-6cff6799c53e9334cb0a86e367e044b0.xml` slot under `PAXPlaytests` in Unity's persistent data directory. The prototype/generated slots stay intact. The local validation player uses a separate disposable directory.
- Terrain, support blocks, markers, beacon meshes, materials, tuning, UI and references are scene/asset authored and manually editable. No external assets or story sources were used; the short Quiet Shoal story text was written locally for this slice. No publishing, package installation, paid API or banked reset.
